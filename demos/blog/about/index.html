About nullsignal

nullsignal is a technical blog about the web platform curated by @ynck-chrl. The focus is on what's actually happening in browsers, specifications, and developer tooling.

Articles cover CSS, JavaScript, HTML, browser internals, and the hardware and systems that run underneath. If it's in a spec, shipping in a browser, or relevant to how code executes on real machines, it belongs here.
