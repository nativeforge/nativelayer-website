About

The project

nativelayer is a project that bring advanced features and capabilities to the base HTML, CSS and Javascript stack.
Implement DOM binding, templating, reactivity, state management, routing, lifecycle management, all while staying close to the web platform primitives, without mandatory compilation or build steps.

Everything runs directly in the browser as ES modules. No bundler, no transpiler, no lock-in.

The developers
